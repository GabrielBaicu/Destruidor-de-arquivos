💥 DESTRUIDOR DE ARQUIVOS

Apagar arquivos nunca foi tão divertido: escolha uma pasta, marque o que quer destruir e acabe com cada arquivo de cinco jeitos diferentes: marreta, fogo, triturador, bombas ou buraco negro.

⚠ No modo real os arquivos são APAGADOS DE VERDADE e não vão para a lixeira. Você escolhe a pasta, marca arquivo por arquivo e ainda precisa digitar APAGAR para confirmar. (Subpastas também são vasculhadas).

Precisa de Chrome, Edge ou Opera (o Firefox e o Safari não permitem apagar arquivos por páginas web). Não instala nada: é só abrir este arquivo.

Para confirmar, digite APAGAR:
PONTOS 0
COMBO x1
RESTAM 0
APAGADOS 0

M: som liga/desliga

🏁 Missão cumprida!
